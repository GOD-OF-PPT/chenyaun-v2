## 4. F37（`DEFERRED` under D08）边界声明

以下非核心扩展功能经 D08 保守基线裁定，在本轮明确标记为 **`DEFERRED`（暂缓实施）**：

1. **自动扫荡 / 一键跳过战斗结算（Auto-Sweep）**：
   - 未新增任何自动扫荡按钮、跳过战斗产出逻辑或离线自动挂机扣资源入口；主线与试炼仍遵循“观察危险 → 破势反击 → 主动领奖”。
2. **9:16 竖屏移动端适配（Portrait Mobile Layout / Virtual Joystick）**：
   - 保持 1440×900 桌面横屏键鼠/手柄验收基线，未承诺或引入移动端触控重构。
3. **长按自动连升 / 自动连扣（Hold-to-Auto-Deduct / Continuous Upgrade）**：
   - 保留 Q2/F18 显式数量批量炼丹与批量淬炼（明确显示数量、总成本、收益差并需玩家主动点击确认），绝不在无二次确认下连续自动扣减灵石或材料。

**未来若重新开启 F37 的准入条件**：须先在决策记录中正式关闭 D08，单列对应预算、防误扣交互合同、独立移动端验收矩阵与旧档回退方案，经审定后在独立分支实施。
